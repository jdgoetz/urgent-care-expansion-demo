# Screenshot Guide

Screenshots in this directory are generated from the deterministic curated public dataset and simplified demo scores.

- map.png: Illinois-filtered default map showing prominent blue circular analysis areas and the violet active-listing area
- market-overview.png: selected market Overview tab and score strip
- competitors.png: competitor intelligence table
- opportunities.png: listed, off-market, and real-estate demo paths
- metrics.png: normalized metric contributions and source lineage
- report.png: rendered first market page from the curated public Word report

Capture at a desktop viewport wide enough to show the working interface, not browser chrome. Refresh screenshots when layout or the curated dataset materially changes. Do not capture private production records or credentials.
