# Screenshot Guide

Screenshots in this directory are generated from the deterministic curated public dataset and simplified demo scores.

- map.png: default multi-state map showing prominent blue circular analysis areas and the violet active-listing area
- market-overview.png: all eight normalized metric contributions in the six-column Overview table
- competitors.png: canonical physical general urgent-care facilities
- opportunities.png: independent listed, urgent-care target, occupational-medicine target, and real-estate paths
- metrics.png: Notes tab with completeness, provenance, geometry, and methodology context

Capture at a desktop viewport wide enough to show the working interface, not browser chrome. Refresh screenshots when layout or the curated dataset materially changes. The Word report is distributed as a DOCX in `docs/sample/` and is verified separately. Do not capture private production records or credentials.
